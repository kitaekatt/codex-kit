Claude Plugins Kit scripts: bridge Claude plugins into Codex, launch across platforms with a private Python fallback, analyze skill compatibility, auto-update the plugin, and migrate from the retired standalone bridge.

These scripts are the runtime side of the kit: they start the bridge, supply a private interpreter when needed, and sync Claude skills into Codex. They also check skill compatibility, update the installed plugin, and recover state from the retired standalone bridge. The layout follows the work each step performs: entry points, private runtime, core bridge, analysis, maintenance, and migration.

Where to start

plugins/claude-plugins-kit/scripts/launch.sh first to trace interpreter discovery, then plugins/claude-plugins-kit/scripts/bridge.py for the sync, marketplace, and state logic behind startup.

Routes

  • Start on POSIX
    1. plugins/claude-plugins-kit/scripts/launch.sh finds an interpreter and starts the bridge.
    2. plugins/claude-plugins-kit/scripts/bridge.py runs the requested command.
  • Start on Windows
    1. plugins/claude-plugins-kit/scripts/launch.cmd starts the PowerShell launcher.
    2. plugins/claude-plugins-kit/scripts/launch.ps1 chooses Python and starts the bridge.
    3. plugins/claude-plugins-kit/scripts/bridge.py runs the command.

Launch and runtime

  • plugins/claude-plugins-kit/scripts/launch.sh is the POSIX entry point; open it to trace interpreter discovery and bridge startup.
  • plugins/claude-plugins-kit/scripts/launch.ps1 is the PowerShell entry point used by the Windows stub; it has the same discovery logic.
  • plugins/claude-plugins-kit/scripts/launch.cmd is the Windows batch stub that starts the PowerShell launcher.
  • plugins/claude-plugins-kit/scripts/runtime.sh is the private-runtime installer for macOS and Linux; it downloads, verifies, and caches Python.
  • plugins/claude-plugins-kit/scripts/runtime.ps1 is the private-runtime installer for Windows; it has the same verify-and-cache behavior.
  • plugins/claude-plugins-kit/scripts/runtime-assets.tsv holds the pinned platform hashes for private Python downloads.

Bridge and compatibility

  • plugins/claude-plugins-kit/scripts/bridge.py is the core bridge; it syncs Claude skills, marketplace data, state, and user settings into Codex.
  • plugins/claude-plugins-kit/scripts/compatibility.py is the scaffold-time compatibility analysis; it resolves capabilities and caches inference results.

Maintenance and migration

  • plugins/claude-plugins-kit/scripts/maintenance.py handles startup convergence and automatic release updates for the installed native plugin.
  • plugins/claude-plugins-kit/scripts/migration.py is the recovery path from the retired standalone bridge to the native plugin.
