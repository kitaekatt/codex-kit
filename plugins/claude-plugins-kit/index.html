• scripts Claude Plugins Kit scripts: Claude-to-Codex bridge, launcher, private Python runtime, compatibility analysis, maintenance, and migration.

Claude Plugins Kit package that forwards installed Claude Code skills to Codex without copying instructions, including its manifest, startup hook, skill documentation, and compatibility data.

This directory is the Claude Plugins Kit, a Codex plugin that exposes user-installed Claude Code plugin skills and personal skills to Codex by generating a thin forwarding plugin for each skill instead of copying the canonical instructions. At the top level, the package manifest declares what the plugin is, a session-start hook keeps the generated bridge maintained, and one skill folder carries the human-facing documentation of how the bridge behaves. The remaining top-level files are compatibility data: the host capability profile, the equivalence mapping table, and a curated override for every known installed skill. Everything the bridge executes -- the launcher, maintenance, and migration -- sits one level down, behind the card at the top of this page.

Where to start

Open skills/claude-plugins/SKILL.md first: it is the skill Codex loads when you ask to explain, refresh, troubleshoot, or remove the bridge, and it decides which reference document you need next. The launcher and the bridge's maintain, sync, and migrate machinery are behind the scripts card above.

Routes

  • Resolve a forwarded skill: read the forwarding wrapper, then the launcher's info for the plugin and skill folder, then the canonical skill's instructions under the returned source root.
  • Refresh the generated catalog: the launcher's sync --install after a Claude-side change; if a reported catalog change is not visible, start a new Codex thread.
  • Retire the old standalone bridge: the launcher's migrate to preview, then migrate --install to apply; if an operation stops, rerun the same command.

The package manifest

  • .codex-plugin/plugin.json -- the Codex manifest: plugin name and version, the skill entry, category, display text, and default prompts. Open it when you change what the plugin advertises itself to be.

Session startup

  • hooks/hooks.json -- the SessionStart hook that runs the launcher's maintain step on startup and resume, with a 300-second timeout. Open it when the bridge maintains at the wrong time, or not at all.

The gateway skill

  • skills/claude-plugins/SKILL.md -- the entry skill that explains, refreshes, troubleshoots, or removes the bridge and points to the two references. Open it when a forwarded skill is missing, stale, blocked by a native plugin, or cannot resolve its source.
  • skills/claude-plugins/references/runtime.md -- the runtime contract: how a forwarded skill resolves its canonical Claude source, what the launcher's info and python commands return, and how compatibility reports and caches behave. Open it for questions about resolution, capability reporting, or running a skill's bundled scripts.
  • skills/claude-plugins/references/maintenance.md -- the lifecycle reference: Claude source discovery order, the generated data root, catalog sync, update cadence, and migrating an older standalone bridge. Open it for questions about refresh, collision, update, or removal.

Compatibility data

  • compatibility-overrides.json -- the curated table of known installed skills: one status per skill -- supported, adapted, or claude-only -- plus the Codex-side instructions to apply. Open it to see how a specific skill is treated, or to add an override for one that misbehaves.
  • capability-profile.json -- the shipped host capability profile for the Codex host; currently an empty list. A user-local file with the same name under the bridge data root overrides it; open it when capability reporting looks wrong.
  • capability-mappings.json -- the shipped equivalence mapping between Claude requirements and Codex capabilities; currently an empty list, overridable the same way. Open it when you add a mapping.

Runtime notes

  • RUNTIME-NOTICES.md -- provenance and licensing for the pinned CPython 3.13.15 fallback: the digests that were checked, the supported platforms, and what the MIT license does and does not cover. Open it before you update the runtime pin.
