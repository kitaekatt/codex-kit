Claude Plugins Kit package that forwards installed Claude Code skills to Codex without copying instructions, including its manifest, startup hook, skill documentation, and compatibility data.

Claude Plugins Kit is the Codex-side package that exposes installed Claude Code plugins and personal skills as local forwarding plugins. It does not copy Claude instructions; it generates wrappers that point back to the canonical skill sources. The package is organized around a manifest, a startup hook, a gateway skill, and compatibility data.

Where to start

Open plugins/claude-plugins-kit/skills/claude-plugins/SKILL.md first. It states the gateway's scope, points to the two references, and sets the rule that a missing or blocked forwarded skill must be reported, not bypassed.

Manifest and startup

  • plugins/claude-plugins-kit/.codex-plugin/plugin.json is the Codex plugin manifest: name, version, display metadata, and the skills directory.
  • plugins/claude-plugins-kit/hooks/hooks.json starts maintenance on startup or resume by delegating to the package launcher.

Skill documentation

  • plugins/claude-plugins-kit/skills/claude-plugins/references/runtime.md explains how a forwarded skill resolves its canonical Claude source, translates paths, checks compatibility reports, and dispatches Python scripts.
  • plugins/claude-plugins-kit/skills/claude-plugins/references/maintenance.md covers discovery order, generated state locations, synchronization, update checks, removal, and migration from the old standalone bridge.

Compatibility data

  • plugins/claude-plugins-kit/compatibility-overrides.json holds per-skill adaptation notes: supported, adapted, or Claude-only behavior for the forwarded catalog.
  • plugins/claude-plugins-kit/capability-profile.json is the Codex host capability profile used by compatibility reports.
  • plugins/claude-plugins-kit/capability-mappings.json maps requirements to host capabilities; the shipped file is empty at version 1.

Runtime notices

plugins/claude-plugins-kit/RUNTIME-NOTICES.md records the pinned private Python fallback, its provenance and licenses, and the platform primitives required before the fallback can run.

  • scripts Claude Plugins Kit scripts: bridge Claude plugins into Codex, launch across platforms with a private Python fallback, analyze skill compatibility, auto-update the plugin, and migrate from the retired standalone bridge.
